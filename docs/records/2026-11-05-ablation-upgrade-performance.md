## 处理性能测量

Node 24.18.0，同机相同输入；预热后各采样 5 次，表中为中位数，前后输出逐字节比较一致。SLS 使用注入的本地响应，包含实际累积和结果序列化，不包含云端查询时间；Markdown 使用公开 `marked.parse`，不包含清洗、DOM、布局和网络。

## 依赖、迁移和设计取舍

- 对照实际发行包和 source map 中的源码检查 marked／Fastify Static，再修改锁文件；仅这两个包升级。保留 Pi／Monaco 内部自行固定的 marked 版本，不强行统一不同调用契约。
- Pi SDK 当前稳定版本仍为 1.5.0，Zod 仍为 4.6.7。现有 saveOutput 与 v3 集合上限补丁尚无等价公共替代，不能删除；安装校验和安全回归继续执行。
- Solid Vite next.56 的主要新增能力涉及 nodeServer 预压缩、服务端函数和 manifest，本项目使用现有 Fastify 同源服务，暂无收益足以迁移入口。保留配套的 Solid 2 RC，不把 npm 的旧 stable 标签误当作升级目标；Vitest 也不为版本号升级。
- 无须改变公共接口、数据库结构或发布迁移。已删除上游替代的 glob override，并沿用公开 tokenizer API、既有序列化预算和 p-map 排空选项；没有增加通用框架或另一套业务规则。
- 现有领域契约、SQLite 配置 owner、分别保护不同状态的队列、跨介质 prepare／rollback／finalize、执行后重授权、DOMPurify 及 SRT 边界均保留。主要简化是消除重复清理实现、无用语言服务依赖和重复扫描，不能以更少代码为由合并不同业务语义。
