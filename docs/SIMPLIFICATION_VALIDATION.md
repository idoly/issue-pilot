## 保留的边界

- 保留所有已发布迁移、journal、实验脚本和实验记录：它们有升级/复现用途，不因生产调用少就删除。
- 保留工作线程、沙盒生命周期、队列与权限校验：承担实际取消、资源隔离和并发约束。
- 保留配置公开投影与开发角色明文展示的独立读取路径，避免合并时把私密字段带入普通配置或 AI 上下文。
- 保留真实使用的9个 MCP 工单工具，不再保留已撤下的底层源码读取执行路径。
- 通用 HTTP 工作仍暂停；不借清理任务新增网络机制。

本轮未修改真实数据库、未调用业务 mutation、未重启 API，也未提交或推送。Web 开发服务会加载样式变化。自动测试均注入临时 state；浏览器仅使用应用只读接口核对展示，Git/工单/附件/成果和 Pi JSONL 未作为实验输入或被修改。

这是一轮针对近期残留的验证，不是整仓死代码证明；文件无引用和固定样本像素相同也不能覆盖所有动态入口与浏览器状态。后续应继续逐问题、小范围验证，不能据此批量删除低调用频率模块。
