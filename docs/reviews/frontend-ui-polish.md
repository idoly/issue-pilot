## 诊断与修改

先检查代码、报告诊断，再在独立演示环境截图复核和修正。范围覆盖运营总览、工单与 Agent 对话、用户／仓库／服务／端点、编辑弹窗及代码浏览器。

| 范围 | 发现 | 原位调整 |
| --- | --- | --- |
| 字体 | 无稳定的界面主字体，路径／数字与正文层级分散 | 本地 Geist，数据与代码使用 Geist Mono，CJK 继续使用系统字体回退；font-display: swap |
| 字号 | 主要表格、辅助文字和状态说明有多处 9–11px，主次难分 | 主要表格／输入 14px，辅助信息 12px，动作与标题使用 14／16／18／20／24px 等固定层级；数字使用等宽数位 |
| 字重与强调 | 品牌使用 800，思考文本和历史修订标题靠斜体区分 | 品牌降到 700，思考文本改正体，修订标题用字重强调；保留业务数据自身的 Markdown 语义 |
| 配色与对比 | 表格说明和工具输出偏暗，停用整行 opacity 降低可读性 | 加深主要辅助文字、提高工具输出亮度；停用以状态与背景表达，保留文本对比；顶部使用中性深色 |
| 公共控件 | 主按钮 13px、小按钮 26px，字段和选择器高度不齐 | 统一按钮、输入、选择器的字号／高度／圆角；hover、pressed、focus 状态统一，业务手机主按钮至少 44px |
| 个人凭证 | 四组直接分割在大容器中，标签与动作层级弱 | 轻底色独立小块、统一间距，动作对齐；桌面四列、手机两列，保留本人身份和配置状态 |
| 人员表格 | 手机隐藏独立的管理权限列，操作区偏紧 | 手机保留角色、管理标记、状态，操作单独成行；筛选及停用开关保持原有行为 |
| 仓库表格 | 手机需要横向阅读地址和服务引用 | 手机按仓库组织纵向信息，地址可换行，使用服务仍可导航；桌面保留表格 |
| 总览 | 指标块只有局部边框，手机刷新按钮单独占一行 | 完整边界和统一节奏，指标数位对齐，手机标题与刷新同排 |
| 运营洞察 | 显示“补充视图／固定高度”等实现说明 | 删除实现文案，保留标题、周期和实际统计分类 |
| 视口 | App 主框架使用 100vh | 改用 100dvh，实际验证手机视口缩短后的布局 |
| 弹窗 | 公共 Modal 已处理视口，页面还用 :has 覆盖到 720px | 删除重复覆盖，统一头部／正文滚动／固定 footer；长表单在手机获得更多可用高度 |
| 表单反馈 | 无效邮箱仍发请求，MySQL／仓库部分错误原样显示代码 | 姓名／邮箱的现有必填检查保留，邮箱就地提示；MySQL 和仓库错误使用具体中文提示，失败保留输入，服务端检查仍保留 |
| DMS 状态 | 编辑区重复展示不可编辑的 InstanceId／DatabaseId／host | 显示“数据库范围已确认”；解析、精确绑定和提交字段保持原样 |
| 键盘 | 缺少跳到内容入口，手机身份选择焦点不可见 | 增加跳转链接，聚焦主内容而不改 URL；补手机身份焦点，装饰 SVG 不进入焦点链 |
| 图标 | 普通页面也加载 Monaco Codicon 字体 | 普通操作使用 Phosphor Regular SVG；编辑器 Codicon 独立模块按需加载，文件格式图标保留 Material Icon Theme |
| 动效 | 默认 easing、渐变骨架，减少动效覆盖不完整 | 200ms 自定义曲线用于轻量反馈，骨架改平色透明度变化；CSS 及错误定位滚动尊重 prefers-reduced-motion，保留即时内容呈现 |
| 清理 | 旧人员表格、旧生产凭证、原生 DB 编辑器和成果预览选择器残留 | 删除失去 DOM 消费方的规则和重复凭证布局、旧弹窗适配，移除未使用 History 图标包装；动态 thinking-* 和编辑器必要规则保留 |
| 页面元信息 | 缺少产品图标和内部应用索引声明 | 增加本地 SVG favicon、描述和 noindex；资源放在现有静态 assets 白名单内 |

业务工作台采用已有绿色主题、紧凑信息密度、固定顶栏和已确认的服务分段导航。技能中的字体、比例、状态和原位修改原则用于本轮；营销 Hero／FAQ、滚动模糊揭示和浮岛导航不属于本轮业务流程。没有更换框架、引入样式库或添加新的 npm 依赖。

## 资源与开销

Geist／Geist Mono 的 WOFF2 和 SIL OFL、Phosphor 的 SVG 路径及 MIT 许可证都来自上游公开仓库。原始 blob／SHA256 记录见 [provenance.json](../../src/web/src/ui/assets/provenance.json)。构建交付 assets/interface-licenses.txt，代码浏览器原有字体／文件图标许可证继续交付。

在相同 Vite preview 版本／选项、同一独立 API 和 1440／390 视口下，普通首屏 Codicon 字体请求由 1 降为 0。首屏字体传输约 153,528 → 141,956 字节，整体已完成资源约 293,757 → 284,160 字节；资源数 7 → 8，包含两个本地 WOFF2，不能宣称请求数量下降。此处为一次可重复静态加载观测，不外推为线上延迟改善。代码浏览器打开后仍按需加载它需要的 Codicon／Monaco 资源。
