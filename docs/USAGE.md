# 使用指南

[文档导航](README.md) · [配置与协议](CONFIGURATION.md)

## 开始前

页面右上角的账号决定本次操作身份。生产环境应由可信网关认证并固定该身份，不把账号切换器当作登录安全边界。遇到权限不足时检查实际账号、角色和管理标记，不通过更换处理人绕过权限。

工单凭证 owner 是处理人，否则为报告人。owner 必须活跃；开发工单要求开发者。准备凭证的方法见[凭证与 owner](CONFIGURATION.md#凭证与-owner)。

## 创建与导入

点击“新建”，选择入口服务和处理方式，填写现象、预期结果、证据范围与验收条件，按需选择处理人、抄送、关联和附件。

| 方式 | 代码权限 |
| --- | --- |
| 正式问题调查 | 正式部署只读快照 |
| 测试问题调查 | 测试部署只读快照 |
| 开发缺陷修复 | 工单私有开发分支 |
| 开发功能开发 | 工单私有开发分支 |

页面新建后自动启动 Agent。所有附件原件与工单一起保存，保存失败不会留下已受理的半张工单。

“钉钉”接受单条记录链接，新工单默认指派给当前用户并启动 Agent；重复来源打开原工单，不重复启动或改派。字段和连接由配置维护，导入参数不能临时替换字段映射。

MCP 客户端先使用 `users_list`、`services_list` 核对身份和可用范围。MCP 创建会自动入队，钉钉 MCP 导入默认不启动；参数详见[入站工单 MCP](CONFIGURATION.md#入站工单-mcp)。

## 阅读与继续对话

工单工作区集中展示对话、描述、附件、关联、代码和工作目录。正文与思考内容先流式显示为纯文本，完成后渲染 Markdown；工具默认折叠，展开查看已保留输出、diff、图片、耗时和嵌套调用。

- “等待执行名额”表示输入已保存、任务仍在排队，不是模型卡死。
- 离开页面不会丢弃应用资源中保存的草稿；切换身份会取消旧身份未发送的工作。
- 不在底部时出现新消息提示，点击提示或聚焦会话后按 Enter 可回到底部；工具卡片保留自身键盘操作。
- 运行中可以按界面提供的方式补充信息或中止，空闲时发送会继续处理。
- HTTP 受理不代表执行完成。请求结果不明时先核对对话和文件，不盲目重发。

费用沿用 Pi 的记录，并区分供应商报告、估算、来源未标明和混合来源，不等于最终账单。嵌套调用“记录不完整”表示记录可能省略参数、调用或未完成状态，不推断缺失结果。

## 检查文件和代码

附件原件不可编辑；需要修改时让 Agent 另存普通工作文件。脚本、表格、报告和查询导出从工作目录预览或下载；超出预览预算不等于不能下载。粘贴到对话的图片属于 Pi 消息，不是上传附件。

代码浏览器提供文件、差异、定位、暂存和提交。调查只读，活动开发工作区可编辑。保存时若报告 `source_file_changed`，先重载核对外部修改，不覆盖冲突。文件保留原有的统一 LF 或 CRLF 换行和 UTF-8 BOM；混合换行或含单独 CR 的文件以只读方式打开，避免整份改写。放弃修改后再切换文件时，即使新文件加载失败，被放弃的草稿也不会自动保存。单个文件超过 `limits.sourceBrowser.fileBytes`（默认 64 MiB）时读取或保存返回 413：内容检查为 `source_file_too_large`，传输层请求体超限为 `payload_too_large`，服务端在分配整份内容前拒绝。Agent 只在用户明确授权时提交／推送，提交信息按应用指引使用简体中文。

服务基线变化不会重置已有开发分支。关联工单最多 `limits.relatedIssues`（默认 20）个，只提供只读证据，不授予其服务或查询权限；引用结论时核对源文件、代码版本与时间。

## 调整范围、解决和重开

服务或处理方式变化使用“变更处理范围”，先检查预检计划再确认；Agent 或冲突预约活动期间拒绝变更。普通补充沿用当前范围。

检查结果后可确认解决，或继续反馈。解决保留对话、附件、工作文件和持久分支；只有满足安全条件的代码目录才回收。重开恢复本地分支，不丢弃未提交内容，也不从远端猜测重建缺失分支。

## 重置会话

开发者在“编辑工单”底部使用“重置”。它先保存字段和附件修改，再创建新会话；旧对话通过“查看历史”只读访问，代码、附件和工作文件不删除。新会话下一条消息按当前范围与凭证准备，不自动运行。

运行中和已解决工单不能重置。保存成功但重置失败会明确提示部分成功；先核对现状再重试，不重复上传已保存附件。

## 设置与统计

个人凭证在“配置 → 用户 → 我的凭证”维护。管理人员打开 API Key／DMS／SLS 编辑时默认勾选共享凭证，取消后才编辑个人组；SSH 仅供开发者。服务页面维护目标，不维护 DMS／SLS 连接密钥。

运营统计按所选周期内**创建**的工单分组，“周期解决”是该批工单当前已解决数量，不是按解决时间计数。同名账号不合并，未分配单独计算。资源统计带采样时间，候选占用不等于实际可释放量。

## 常见提示

| 提示 | 下一步 |
| --- | --- |
| 缺少或失败的凭证 | 检查工单 owner 的个人组／所选共享组，不期待自动换身份 |
| 配置版本冲突 | 保留草稿，重载或等待相关活动结束 |
| 写入成功但刷新失败 | 重试读取，先确认已保存结果 |
| 消息结果不明 | 查看会话和文件后再决定是否重发 |
| 工作区、会话或 Git 异常 | 保留现场和错误码，交由维护者按[运维手册](RUNBOOK.md)检查 |
