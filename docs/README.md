## 文档如何维护

- 当前规则以源码、根配置和锁文件为准；文档不是第二套可执行配置。
- 工作区代码、运行中的服务、宿主工具和历史验收是四种不同事实。修改文档不代表已发布或重启。
- 人读指南说明“怎么做”；AI 参考说明“必须保留哪些约束、去哪改、怎么验证”。同一细节只在所属主题维护，其他位置用链接。
- 只维护宿主机部署与本地验证。Playwright／SSH 容器用于测试，不承载应用部署。
- 变更后核对相对链接、标题锚点、命令语法及 `git diff --check`。
- 直接更新现行文档，不为每轮修改新增报告或保留旧版；迁移记录是明确且有界的例外，旧经验不改写为当前事实。删除文档历史不等于可以删除业务数据、迁移 SQL、测试夹具或恢复材料。
